GreyStudio Command Center AI Agent Context

This repository is the operating system for GreyStudio and the owner's personal/business management.

Preserve existing data and UX unless there is a clear reason to improve it. Keep financial records traceable and never expose secrets to the browser.

Business: website development, graphic design, photography, video editing, printing and related creative services. The physical shop also earns from money transfer commission, Xerox/copying, passport photos, photo frames and related walk-in services.

Goals: build GreyStudio into a creative marketing agency; improve monthly profit materially; long-term target ₹2–5 lakh/month profit; keep rent, EMIs and debt repayment visible.

Planning baseline: survival about ₹28,300/month; debt target ₹6,75,000; earlier 12-month repayment target about ₹56,250/month; minimum studio generation target about ₹85,000/month. These are editable settings, not business-logic constants.

Quick transaction syntax: 100+, +100, 100v, V100 = incoming. 100-, -100, 100p, P100 = outgoing. Optional description may follow, e.g. 500+ passport or 150- paper. Plain numbers follow the current UI convention as incoming.

Shop categories: Money Transfer, Xerox, Passport Photos, Photo Frames, Printing, Stationery, Photography, Graphic Design, Website Development, Video Editing, Other.

Daily closing: record actual end-of-day Cash Counter, Bank Account and AEPS Account balances separately from revenue/expense transactions. The latest closing snapshot is displayed on the dashboard; never infer an account balance from sales unless account-level transaction tracking has explicitly been added.

AI actions that change financial/business records require explicit user approval. Recommendations must distinguish facts from assumptions. Preserve mobile/PWA usability. Update this file and docs/AI_CONTEXT.md when durable business rules change.
